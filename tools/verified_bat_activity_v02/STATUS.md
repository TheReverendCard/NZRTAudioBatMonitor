## Dashboard functionality (local host tests passed)

- Keeps Shed-only **AR4, XiaoSD, XiaoRT** grade **4/5** verified activity, with background period and real minute-union semantics. South appears only in separately labelled XLSX export; Other and historical combined with unresolved provenance never enter Shed heatmap/index. Human hotkey review is required, machine-only AviaNZ predictions are excluded. Date groups are evening dates by Pacific/Auckland noon-to-noon, including overnight after midnight and DST real-minute uniqueness.
- **Both** 10-minute heatmap and Time-of-Night pattern now use **16:00 through 09:00 the following day**. Hourly pattern uses 17 aligned columns, unique evening dates per hour, and the same date/grade filters as the heatmap. Full 24-hour option was removed so the two chart axes do not silently diverge. There is still no proof of full recorder/reviewer coverage; blank cells are *not* confirmed absences.
- New **Recognizer Training & Performance** section: inventory of explicit human grades **1–5**, distinct BMP recordings and WAV-linked reviewed recordings, 4–5 positive/1–2 negative/3 uncertain, site/source counts; includes historical combined folders as `historical-unassigned`, counted as reviewed but held out from training-*readiness* target until attribution can be established. No source media rewritten, model weights touched, or retraining launched by a dashboard rebuild.
- When frozen `Training_Phase1/{spectrogram_candidates,wav_candidates}.csv` manifests are present, compares exact old annotation SHA and source paths against current grades. Reports new-positive, new-negative, distinct new nights and what remains to **provisional operator-configurable** planning targets. The defaults BMP=20 new positives,100 negatives,5 nights; WAV=10 positives,50 negatives,5 nights are **NOT scientifically validated sufficiency conditions or automatic model triggers**. If no frozen audit exists, the since-last-training progress is unavailable; never invent current model training membership.
- Displays five known comparative report snapshots from owner-provided experiments: BMP linear/MLP/CNN on **the SAME 220 validation BMPs** (BMP linear and MLP TP27,FN1,FP1,TN191; CNN TP27,FN1,FP30,TN162), WAV linear/MLP on **the SAME 616 previously diagnosed historical test WAVs** (linear TP8,FN1,FP2,TN605; MLP TP8,FN1,FP0,TN607). These cohorts have **exact content+human-label hash identifiers**: BMP `9a606f4cdc9737822722aeb96f2ccd0484b929e39300b446fed8f2c6c022d298`, WAV `bdc3e4af279d847b6b93e30e0f5f3fcb935ecd81c4bb60e99275705ce45d10bb` so a later model's identical frozen evaluation can be compared fairly. Do NOT compare scores across different cohort IDs or suggest this is new field accuracy.
- Plots accuracy, precision, bat recall on **0–100% full axes**, with TP/TN/FP/FN counts and deltas from first model *only within matched cohorts*. Counts and comparison are source-/label-frozen snapshots, not model predictions on newly arriving files.
- `model_progress.py` has an **explicit operator-only append-once evaluation registry**, `Daily_Run_Reports/Verified_Bat_Activity/Model_Registry/evaluations.json`. It accepts saved model report plus frozen labelled prediction CSVs, hashes/report identity, refuses duplicate reports and corrupted registry. Preferred `register_pair_once` atomically freezes **newly reviewed daily** and **all previous historical retrospective** model evaluation cohorts in one event **only when a new model run has already produced those predictions**; rejects shared media between new and historical, distinguishes unknown holdout independence and historic in-sample risk. Daily tool never runs inference or changes a snapshot. Actual *new-model inference and training-time heldout-membership proof* is **not implemented** by this dashboard and remains a new training-pipeline acceptance gate in #14/#22.
- XLSX format still preserves the exact first three sample workbook sheet titles/column names: **Time Stamps**, **Presence Absence**, **Per Time Period**; fourth **Review provenance**. Human grade is never converted to certainty. Grade4/5 only in verified-detection exports.
