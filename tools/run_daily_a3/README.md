## Evidence and limits
- For every accepted AR4 grade 4/5 or legacy verified LT, search overlapping intervals within ±180 seconds of the configured AR4 estimate. Include SD event and periodic WAVs regardless of AviaNZ classification. For a co-located SD .wav.json receipt, validate the PCM hash before using its UTC time. Otherwise use session/sample time or the supported UTC filename via the timeline. Time window can be changed with numeric `acoustic_search_seconds` in BatDailyTool/config.json or its per-day overrides. A clock error outside the window may still produce no candidate.
- Compare 28–45 kHz envelopes on a 2 ms grid. Rank by normalized envelope correlation (55%), one-to-one pulse coincidence within 20 ms (30%) and correlation within three frequency bands (15%). Show up to three alternatives; retain tested filenames, numerical scores, overlap and candidate lag in pairs.json. Insufficient overlap/evidence yields no convincing match; competing clip or lag scores within 0.08 can yield ambiguous. A skipped/unreadable search file is reported as incomplete. The scores are heuristic, not probabilities, species labels or proof of bat identity.
- Cached features and lag scores under Daily_Run_Reports/Acoustic_Features_v1 use path, size, mtime and algorithm revision. Delete this derived cache if files were externally replaced while preserving size and mtime. No WAV copying for matching.
- A probable candidate provides a provisional clock reference: SD UTC minus acoustic lag, compared to configured AR4 UTC. Report total correction relative to the AR4 filename offset convention and the residual beyond configured adjustment. Two distinct passes separated by at least 30 s can bracket a correction. Fit robust linear drift only with at least three over 30 min. Split at residual jumps >4 s and reject fits with max residual >2 s. Re-search bracketed intervals at the fitted offset, without dropping original candidates. No extrapolation or rewrite of config. Reported residuals describe the fit, not a calibrated timing confidence interval.
- Only probable pairs receive an RT comparison: use matched pulses in SD UTC, ±1 s for quantised journal times. Show actual overlapping triggers, RT-SCORE class, ML decisions, whether a received RT clip spans the pulses and nearest trigger for context. Absence is “no logged trigger/prediction,” not a training negative. Live index, conventional timing cards and stock recogniser output remain separate.
- No automatic promotion to training, pair label transfer or acoustic acceptance of machine-only AR4 candidates. South/Other/reference data are excluded.

## Verification and rollout

Lag 2.814 s, correlation 0.7979, 11 corresponding peaks, 4.822 s overlap, clock correction approximately +95.48 s. Five damaged candidate files in a separate mixed run correctly forced an incomplete verdict. An identical second candidate forced ambiguity. Synthetic independent anchors tested drift and jump separation.
