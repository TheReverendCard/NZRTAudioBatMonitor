# Full-session FastAviaNZ daily review

Run Daily now stages all eligible recordings from its prepared review list in one FastAviaNZ window.  A first-time run finishes recorder and historical intake before opening that window.  Previously staged work is reconciled at startup.  Closing early saves valid grades through the existing conflict checks and leaves unfinished recordings available on the next run.  An empty queue skips the GUI.  Review All Unreviewed retains its default batch of 150 and its configurable range of 1 to 500.

The change removes the daily batch relaunch loop and passes an explicit unlimited size to the shared queue.  The queue still validates standalone limits.  Baseline repair covers the full daily set.  Newly staged daily links include the recording date in reverse chronological order within their priority tier, so later nights are reached first by filename navigation.  Existing staged links keep their filenames.  Sync avoids reading the review ledger for ordinary ungraded files and loads it once when grade reconciliation requires it.

The follow-up source delta is full-session.patch in the same folder as installed-runner.patch.  Apply it after the RT intake patch to a matching installed-source tree.  The Windows download contains the cumulative program update and supports both the pre-RT installation and the previous RT update.  Its installer verifies the current program files, takes a backup and uses the daily-run lock.

An isolated test seeded a standalone 150-file queue, prepared 625 eligible daily files together, repaired a missing machine baseline beyond file 500 and excluded an already-graded recording.  The test saved two grades, closed, reopened the 623 remaining files in one session, synced those grades and confirmed an empty subsequent run.  A separate offscreen test used the installed AviaNZ Qt file list and Fast Review navigation to traverse all 625 staged BMPs and step back from the last entry.  The tests substituted the live human reviewer.  The RT and Fast Review compatibility suite passed 30 tests with isolated application settings.  Installation and repeat installation were checked on copies of both supported program versions.
