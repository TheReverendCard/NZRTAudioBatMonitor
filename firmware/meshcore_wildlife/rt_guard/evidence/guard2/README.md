# GUARD-2 qualification evidence

Status:  bench candidate.  The full GUARD-2 PlatformIO build and physical board gate are outstanding.  GUARD-1's separate evidence is retained one directory up.

* Native C++11 detector regression:  1,526 checks, including 600 power comparisons to an independent direct DFT, an evolved-only synthetic 41 kHz burst, a legacy-only observation, unchanged shadow-only behaviour, active pressure, simulated slow kernels and reacquisition after an input gap.  Optical, radio, microphone and DMA behaviour are not simulated.  The FFT preserves frequency measurement in the tested inputs; no wall-clock speedup on real silicon is implied.
* The same detector suite cross-compiled and ran on the emulated ESP32-S3, esp-emu 0.50.0 / ESP-IDF 5.4.2.  See detector.json and detector-guest.txt.  The test clock simulates compute budget expiry deterministically.  A second guest induced a DSP stall, restarted, retained the fault, and avoided a second restart (restart.json).  New candidate objects were relinked with existing IDF platform archives; CI also provides a fresh IDF build.  The actual production-clock detector translation unit separately cross-compiled for S3 using its existing ML declarations and a minimal Print declaration.  Neither is the full Arduino/MeshCore application.
* Offline PCM replay:  nine intact 96 kHz mono SD WAVs, five malformed or truncated inputs excluded, five profiles, two calibration choices.  No RT WAV for the November 14 miss.  Decoded SD PCM bypasses RT microphone/PDM capture.  The replay uses model work with no simulated timing pressure.  The November 5 grade-5 positive (archived user review) produced an event under every profile with either calibration.  With per-clip calibration, legacy and evolved assist flagged 1/2 grade-1 recordings; audible assist flagged 2/2.  With a common background calibration, both assist profiles and legacy flagged 2/2.  The common background is itself one of the grade-1 clips; this is a smoke test, not an independent validation split.  Event counts within a clip are not bat counts.  Report includes all nine clips; no grade is inferred for an unreviewed WAV.  A grade-2 file is kept distinct.  No field sensitivity, specificity, or power claim follows.
* Builder staging test:  exact PASS-1 and GUARD-1 inputs produce identical candidate sources; mixed/modified sources rejected.  Physical transcript validator exercises pass/fail for incomplete coverage and missing selected-detector evidence.  See parent README for the 30-minute board test.  Field deployment remains manual.
